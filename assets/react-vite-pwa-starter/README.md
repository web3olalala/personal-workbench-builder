# Starter notes

This is an optional neutral shell for a brand-new project, not a finished dashboard or visual template. It requires Node.js 20.19 or newer.

After copying, run `npm install` and `npm run build`. Before a production PWA release, replace the placeholder name, metadata, and SVG icon; generate and test 192px and 512px PNG icons for broad installability. Add data storage only after the data mode is confirmed.
